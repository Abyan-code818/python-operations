# Python Operations

A simple Python command-line application that combines three mini programs into one interactive menu. This project was created as part of my journey in learning Python programming.

## Features

This application consists of three main programs:

### 1. Simple Calculator
A basic calculator that supports four mathematical operations:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

### 2. Simple Temperature Converter
Convert temperatures between four different units:
- Celsius
- Fahrenheit
- Reamur
- Kelvin

Supports conversion between different temperature units.

### 3. Simple BMI Calculator
Calculate Body Mass Index (BMI) based on the user's weight and height.

The program displays the calculated BMI value and its corresponding category.
