# Python Storage

Selamat datang di Python Storage!

Repository ini merupakan tempat penyimpanan kumpulan mini project yang saya kembangkan menggunakan bahasa pemrograman Python.

## Tentang Repository

Repository ini dibuat sebagai bagian dari perjalanan belajar saya dalam memahami dan mengembangkan kemampuan pemrograman menggunakan Python.

Setiap mini project dibuat untuk melatih pemahaman terhadap konsep dasar pemrograman, meningkatkan kemampuan berpikir logis, serta mengembangkan keterampilan dalam menyelesaikan berbagai permasalahan melalui kode program.

Seiring bertambahnya pengetahuan dan pengalaman, repository ini akan terus diperbarui dengan berbagai project baru.

## Konsep yang Dipelajari

Beberapa konsep pemrograman yang diterapkan dalam repository ini meliputi:

- Variabel dan Tipe Data
- Operator
- Percabangan
- Perulangan
- Fungsi
- List dan Dictionary
- Exception Handling
- Modular Programming
- File Handling
- Object-Oriented Programming

## Teknologi yang Digunakan

- **Bahasa Pemrograman:** Python
- **Code Editor:** Visual Studio Code
- **Version Control:** Git dan GitHub

## Tujuan Repository

- Memperkuat pemahaman terhadap dasar-dasar pemrograman Python.
- Melatih kemampuan berpikir logis dan pemecahan masalah.
- Mengimplementasikan konsep pemrograman melalui project sederhana.
- Mendokumentasikan perkembangan proses belajar pemrograman.
- Membangun portofolio project sebagai bekal pengembangan kemampuan di bidang teknologi.

## Penulis

Repository ini dibuat dan dikelola secara mandiri sebagai bagian dari perjalanan belajar dan pengembangan kemampuan pemrograman saya.
