# Python Operations

A simple Python-based program that combines three basic mathematical and conversion operations into one interactive application. This project was created as a beginner-level Python mini project to practice fundamental programming concepts.

## Features

This program provides three main features:

### 1. Simple Calculator
Perform basic mathematical operations:
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulus (`%`)
- Exponentiation (`**`)

### 2. Temperature Converter
Convert temperatures between four different units:
- Celsius
- Fahrenheit
- Reamur
- Kelvin

Supports conversion between different temperature units.

### 3. Body Mass Index (BMI) Calculator
Calculate Body Mass Index (BMI) based on:
- Body weight (kg)
- Height (m)

The program also provides a basic BMI category based on the calculated result.

## Python Concepts Applied

This project implements several fundamental Python concepts:

- **Functions (`def`)** – Organizing code into reusable functions.
- **While Loops** – Repeating program execution and validating user input.
- **Conditional Statements (`if`, `elif`, `else`)** – Handling different operations and program choices.
- **Exception Handling (`try` and `except`)** – Preventing invalid input from interrupting the program.
- **User Input (`input()`)** – Allowing users to interact with the application.
- **Type Conversion (`int()`, `float()`, `str()`)** – Converting user input into appropriate data types.
- **Return Statement** – Controlling function execution.
